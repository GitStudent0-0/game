# Программная реализация настольной игры на шестиугольной сетке

Поддерживаются две версии: классическая и модифицированная.  
Возможны варианты игры: для двух игроков или против компьютера.

## Классическая версия
1. Игроки поочередно соединяют две точки линией длиной 3.
2. Если на ходе образуется треугольник, туда помещается фишка игрока.
3. Игра заканчивается, когда все места на поле заняты.
4. Выигрывает тот, у кого больше фишек.

## Модифицированная версия
1. Игроки поочередно соединяют две точки линией длины от 1 до 3.  
   Если точка использовалась более 4 раз, она становится недоступной.
2. Если образуется треугольник, туда ставится фишка.
3. Игра заканчивается, когда нет возможных ходов. Выигрывает игрок с большим количеством фишек.

> **Длина линии** – количество шагов (отрезков) на шестиугольной сетке между соединяемыми точками.

**Ускоренная партия:** побеждает тот, кто первым расставит 10 фишек.
